Your Question: "Where will the output be stored for the test scenarios?"

QUICK ANSWER:
═════════════

Test outputs are stored in TWO places:

  1. test_cases.xlsx
     └─ You manually update the Status column
     └─ Tracks: Pending → Pass/Fail

  2. output/ folder
     ├─ output/reports/test_report.html      ← View in browser
     ├─ output/coverage/html/index.html      ← View in browser
     ├─ output/logs/test_execution.log       ← View in terminal
     └─ output/reports/junit.xml             ← For CI/CD

═══════════════════

Step 1: Review Test Cases
  └─ Open: tests/test_cases.xlsx

  └─ Command: cd tests && pytest test_router_sample.py -v

  └─ Test Report: start output\reports\test_report.html

  └─ Open: test_cases.xlsx
  └─ Update: Status column (Pending → Pass/Fail)
  └─ Save: File
