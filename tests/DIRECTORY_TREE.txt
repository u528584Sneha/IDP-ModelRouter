================================================================================
                        HOW TO USE THIS STRUCTURE
================================================================================

1. MANUAL TRACKING (You Update This)
   └─ File: tests/test_cases.xlsx
   └─ What: Update Status column → Pending/Pass/Fail
   └─ When: After running tests

2. AUTOMATED RESULTS (Pytest Generates These)
   └─ Folder: tests/output/
   └─ Created when: pytest runs
   └─ Contains:
      ├─ tests/output/reports/test_report.html
      ├─ tests/output/coverage/html/index.html
      ├─ tests/output/logs/test_execution.log
      └─ tests/output/reports/junit.xml


================================================================================
                    QUICK START - COMMANDS TO RUN
================================================================================

Run Tests:
  cd tests
  pytest test_router_sample.py -v

View Test Results (HTML):
  start output\reports\test_report.html

View Code Coverage (HTML):
  start output\coverage\html\index.html

View Logs:
  cat output\logs\test_execution.log

Update Manual Tracking:
  open test_cases.xlsx

================================================================================
                     STORAGE LOCATIONS SUMMARY
================================================================================

Manual Test Tracking:
  Location: test_cases.xlsx
  Sheet: Test Cases Overview
  Column: Status
  What: You update this with Pass/Fail

Automated Results (Pytest Generates):
  Location: tests/output/

  HTML Reports:
    tests/output/reports/test_report.html      (view in browser)
    tests/output/coverage/html/index.html      (view in browser)

  XML Reports (CI/CD):
    tests/output/reports/junit.xml
    tests/output/coverage/coverage.xml

  Logs:
    tests/output/logs/test_execution.log


================================================================================
                      WHAT GETS STORED WHERE
================================================================================

When You Run: pytest test_router_sample.py -v

Files Created:
  ✓ output/reports/test_report.html         HTML test results
  ✓ output/coverage/html/index.html         Coverage report
  ✓ output/reports/junit.xml                JUnit XML (CI/CD)
  ✓ output/coverage/coverage.xml            Cobertura XML
  ✓ output/logs/test_execution.log          Detailed logs
  ✓ output/logs/failures.log                Failed tests only

Console Output:
  ✓ 10 passed, 1 failed in 2.45s            (immediate feedback)

Manual Update:
  ✓ test_cases.xlsx Status column           (you add Pass/Fail)
